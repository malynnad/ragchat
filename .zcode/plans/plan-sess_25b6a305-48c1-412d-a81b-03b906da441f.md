# RAGchat 项目重启计划：rag_kb → 本地记忆陪聊 App

## Context

延续上一会话（拉取 chat-demo → 讨论本地 LLM 方案）的结论：把你自己的 `rag_kb`（Flutter + nobodywho 端上推理）改造成**简化版本地 LLM 聊天 app**——记忆自动提取、本地保存、可导出继承，人设卡，速度优先小模型。项目已拷入本工作空间 `/Users/dannylam/Documents/Code/RAGchat/local-vec-rag`（6.5G 中 99.9% 是垃圾，真实资产仅 ~900K）。

已确认的决定：**RAG 文档功能彻底移除**（旧表数据保留不动）、**release APK 直接删除**。

探索结论：代码分层极干净——`ModelGateway` 隔离原生风险，聊天页/模型下载/token 预算/风格人设/settings.json 全部可复用；文档管线（parser/chunker/docs 页/引用）是可整体剥离的部分。~105 个测试中约 2/3 直接存活。

## 阶段 2：MVP 实现

### 2.1 数据层
- 新建 `lib/chat/app_db.dart`（替代 `vector_store.dart`）：sqflite 打开 + **幂等迁移升 v3**（沿用 `_createSchema` + `IF NOT EXISTS` 模式），新增表：
  - `memories`：id/content/kind(fact|preference|event|relation)/importance(1-5)/embedding(预留 NULL)/created_at/updated_at/last_used_at/source/active(被取代置 0 不删)
  - `sessions` + `turns`：会话历史持久化
  - 旧 documents/chunks/categories 表**原样保留不动**
- `store_migration_test.dart` 扩展为 v3 真值源测试

### 2.2 记忆管线 `lib/chat/memory_service.dart`
- 提取：复用聊天模型（`ModelGateway.generate`），prompt 输出 JSON `{add, update, deactivate}` + importance/kind；MVP 触发 = 记忆页手动按钮 + 「新对话」时异步跑一次
- 去重/冲突：新条目 vs active 条目做文本相似度（复用 `models.dart` 的 `cosineSimilarity` + 字符 bigram），高分归并 update，矛盾旧条目置 active=0
- 提取 prompt 质量是核心调优点（ADR-0001 的教训写进注释）

### 2.3 人设卡
- 新建 `lib/app/persona.dart`：`PersonaCard{name, personality, style, addressTerm, boundary}`，多卡可切换，内置 2-3 张预设；百字级（0007 教训）
- `settings.dart` 扩展（沿用 `?? 默认值` 向后兼容模式）；`settings_page.dart` 的「回答风格」区替换为人设卡管理（增删改/切换/预览）

### 2.4 聊天服务与 UI
- 新建 `lib/chat/chat_service.dart`（替代 `rag_service.dart`）：保留 ask() 流式骨架；`buildMessages()` = system（人设卡 → 核心记忆清单按 importance 排序）→ 历史 Q/A → 当前问题；无 embed/检索/引用/拒答
- `token_budget.dart` 复用，预算改为人设+记忆 ≤800 tokens，超限仍触发 `AnswerContextFull`
- `qa_page.dart`：剥掉引用/来源面板/分类筛选/拒答提示，保留气泡/流式/停止/上下文用量%/新对话；启动时恢复上次会话
- `app_state.dart`：剥掉 ingest/文档/分类/重建索引，保留模型管理/下载/切换/预热，接入记忆与会话
- `ios_shell.dart`：三 Tab 改为 **聊天 / 记忆 / 设置**；新建记忆页（按 kind 分组列表、编辑/删除/停用、手动提取按钮）
- `model_prep_page.dart`：嵌入模型改为可选（MVP 不需要）；`model_catalog.dart` 默认推荐切到 Qwen3-4B 速度档，尝试补 Qwen3-1.7B 条目（hf-mirror URL 需验证，失败则跳过）

### 2.5 导出继承 `lib/chat/memory_exchange.dart`
- 版本化 JSON：`{schemaVersion:1, exportedAt, activePersonaId, personas[], memories[]}`；导出写文件 + 系统分享面板；导入用 `file_picker`，按 id upsert、冲突取 `updated_at` 新者；不导出 embedding（换嵌入模型即失效，v2 重嵌）

### 2.6 RAG 剥离清单
- 删除：`docs_page.dart`、`document_parser.dart`、`chunker.dart`、`rag_service.dart`、`vector_store.dart`（逻辑迁入 app_db/memory_store）
- 测试：删 `rag_service/document_parser/chunker/category/docs_category_dialog/vector_store/embed_switch` 测试，新增 `memory_store/memory_service/persona/memory_exchange/chat_service` 测试（`FakeGateway`/`openTestStore` 基建全复用）
- `pubspec.yaml`：移除 `syncfusion_flutter_pdf`、`archive`、`xml`；保留 `file_picker`（导入用）、`sqflite`、`nobodywho`
- `verify_page.dart` 保留（真机诊断对速度优先选型仍有用）
