## 关键设计决策

- **分类不经过嵌入模型**：documents.category 元数据标签，检索 SQL 先 WHERE 过滤再算余弦。改分类零重嵌成本。
- **会话机制**：见 ADR-0006（Dart 持有纯 Q/A 历史、每轮重建消息表、complete()、contextShift 关、90% 预算预检、追问拼问兜底、新对话显式清空、不持久化）。
- **人设**：见 ADR-0007（风格句追加在 RAG 底线后）。
- **DB v2 迁移**：schemaVersion 2；documents.category 列 + categories 表 + meta 表；onUpgrade 与 onCreate 共用幂等建表（IF NOT EXISTS + PRAGMA 列检查 + 种子 ignore）。旧库升级数据完好、文档归未分类。
- **主题单点**：theme.dart 集中 buildLightTheme/buildDarkTheme，mac 风格 skill 到位后只换此处与组件层。
- **历史不持久化**：会话重启即清（用户决策）。

## 真机冒烟清单（用户输入中文，agent adb 截图验证）

1. 问答：发送后输入框清空；气泡同页；[n] 可点；参考来源面板见分数。
2. 会话：故宫 → 它有多大（兜底生效）；连问数轮百分比上升；新对话清空。
3. 分类：新建「历史」移入故宫；范围「历史」命中；范围外拒答；移回未分类无需重建。
4. 模型：切换生成模型重载问答正常；换嵌入 → 横幅 → 重建 → 恢复；候选下载小文件（嵌入 0.6B）验证进度与指派。
5. 人设：通俗讲解风格变化；自定义生效。
6. 回归：拒答、停止、删除级联、清空知识库。
7. 视觉：mac skill 到位后另做一轮（阻塞项）。
