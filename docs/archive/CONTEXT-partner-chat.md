# CONTEXT — 术语表

本文件是项目的纯术语表，只放术语定义，不放实现细节与规格说明。

## 已敲定术语

| 术语 | 定义 |
|------|------|
| 长期记忆 | 跨对话保留的关于用户的关键信息（如名字、喜好、聊过的重要事情）。新开对话时模型仍能"记得"用户。是本项目"记忆功能"的明确含义。 |
| 会话内上下文 | 同一对话内的前文消息，随每次请求发送给模型。任何聊天程序的基础能力，不属于本项目所说的"记忆功能"。 |
| 本地模型 | 用户手机上通过 Termux 运行的 Ollama 实例，提供 OpenAI 兼容 API。聊天程序不依赖任何云端模型服务。 |
| 事实条目 | 由模型从对话中提取的关于用户的一条关键信息（如"用户叫X""喜欢Y"）。长期记忆的存储单位，用户可查看、可删除。 |
| 记忆清单 | 全部事实条目的集合。新对话开始时注入模型提示词，使模型"记得"用户。 |
| 对话 | 单对话模式：同一时间只有一个聊天窗口。当前对话保存在本地，刷新页面不丢失。 |
| 新对话 | 清空当前对话上下文、从头开始的动作。记忆清单不受影响，跨对话保留。 |
| 自动提取 | 记忆提取机制：聊天空闲一段时间后自动在后台提取新的事实条目；"新对话"清空上下文前也会先提取。无需用户手动操作。 |
| 人设 | 唯一的聊天角色设定：名字 + 性格/说话风格描述，用户可随时编辑。注入模型的系统提示词，与记忆清单一对一绑定。 |
| 小后端 | Termux 中运行的轻量服务：托管前端页面、转发 Ollama 请求、把记忆和聊天记录存为手机上的文件。 |
| PWA | 渐进式 Web 应用。前端形态：可安装到手机桌面，点图标全屏启动，体验接近原生应用。 |
