# CONTEXT — RAG 知识库术语表（已归档）

> 2026-11-16 归档：项目目的转向本地记忆陪聊 app（见 ADR-0009），现行术语表见 CONTEXT.md。

| 术语 | 定义 |
|------|------|
| RAG 问答知识库 | 旧项目目标：把用户文档摄取为本地知识库，按问题检索相关内容，交给本地模型生成答案。 |
| 知识源 | 摄取进知识库的用户文档，中文为主，格式含 PDF、DOCX、TXT、Markdown、CSV。 |
| 生成模型 | App 内的 GGUF 语言模型，基于检索到的内容生成答案。 |
| 嵌入模型 | App 内的 GGUF 向量模型，把文档分块和用户问题向量化，必须支持中文。 |
| 分类 | 文档上的元数据标签。检索时 SQL 先按分类过滤再算余弦；改分类不需重新嵌入。删分类不删文档，其文档归「未分类」。 |
| 回答风格预设 | 人设的受限形式（ADR-0007）：默认/通俗讲解/严谨考据/自定义风格句，追加在 RAG 底线之后，只调整表达，不改变「仅按资料回答」。 |
| 引用 | 答案附带的来源文档与段落，可点开查看原文。知识库答案的可核查机制。 |
| 摄取 | 把文档解析、分块、向量化并写入本地索引的过程。由文件多选导入触发。 |
| 分块 | 文档切分出的文本片段，向量化与检索的基本单位。 |
