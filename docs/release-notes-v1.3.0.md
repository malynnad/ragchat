# RAGchat 1.3.0

本地优先的记忆陪聊 App 第四个发行版：模型默认在手机端跑，聊天记录、记忆、人设全部留在本机；想要更强的对话可以切到云端 API。

## 这个版本有什么

- **端上推理**：nobodywho（llama.cpp）在 CPU 上直接跑 GGUF，不走云端
- **长期记忆**：从对话提取事实 / 偏好 / 事件 / 关系，带重要度，可编辑、停用、删除
- **会话持久化**：关掉 App 再打开，最近会话还在；`new` 开新对话时自动整理记忆
- **两个人设槽位**：本地模型用「大肥鱼」短版（六字段，约 173 token），云端 API 用同一个人的长版（约 1.3k 字）。点槽位切换后端，两张卡内容各自保存、互不覆盖，改名也会跟着走
- **人设编辑**：短人设填六项字段，长人设整段编辑；编辑器里能看到当前后端的 system 预算（本地 800 / 云端 6000）
- **采样可调**：温度三档（稳定 0.4 / 平衡 0.6 / 活跃 0.9），即时生效
- **模型可选 4B**：Qwen3.5-4B Q4（2.55 GB）作为默认档，2B 留作速度档；首次打开可以先「稍后配置」进界面
- **可选云端后端**：设置里能切到 DeepSeek（或任意 OpenAI 兼容 API），key 存系统 Keychain/Keystore；不填 key 时仍走本地。默认模型 `deepseek-flash`，要更强可改 `deepseek-v4-pro`
- **下载走魔搭**：模型源换成 ModelScope（国内直连），实测 4B 2 分 37 秒下完，约 17 MB/s；下载器自己实现，支持 >2GB 文件
- **纸页与档案界面**：暖白纸底 + 档案编号 + 只在交互层用玻璃，单一纸墨色
- **细节**：启动直接进对话（无开机动画、无系统 splash 图标）、60 秒生成看门狗、键盘弹起时 dock 滑走、删库 / 恢复预设需按住进度条填满

## 1.3.0 新增

- **导出 / 导入备份**：设置 → 07 / STORAGE
  - 导出：生成 `.ragchat.zip`（会话 + 轮次 + 记忆 + 人设/温度/语音/后端设置），存到手机任意位置
  - 导入：选文件 → 预览「N 个会话 · M 轮对话 · K 条记忆」→ 确认后覆盖恢复
  - **不含 API key、模型路径、模型文件与用量账本**；模型文件需要重新下载或导入
  - 换机、重装、清数据前先导出，就不怕丢聊天和记忆了
- 备份格式带版本号（`manifest.version`），更新版本的备份会被旧版 App 拒绝，不会悄悄读坏

## 1.2.0 新增

- **云端费用可见**：云端回复底部显示本轮 token（↑输入 ↓输出）；设置 → 05 / BACKEND 显示「今日 / 累计」的 token 与估算金额、调用次数
- 用量存本地 SQLite（`usage_log`），不联网、不上传；「删除聊天数据」会一起清空
- 价格按官方闲时价估算（flash 输入 ¥1 / 输出 ¥4，pro 输入 ¥4.5 / 输出 ¥13.5，每百万 token），高峰翻倍，界面标「≈」仅供参考
- 本地模型不产生费用，也不会记账

## 1.1.0 新增

- **语音朗读（系统 TTS）**：助手气泡底部多了「朗读 / 停止」，点哪条读哪条；完全离线、免费、不要 key
- **设置 → 06 / VOICE**：新回复自动朗读开关 + 三档语速（慢 0.35 / 正常 0.5 / 快 0.65）
- **语音参数**：新回复自动朗读、语速与音调改成滑块连续调节（语速 20–80%，音调 0.70–1.30）；发音人跟随系统默认 TTS 引擎
- 没有可用语音引擎时会提示，装一个系统中文 TTS 引擎即可
- 模型目录调整：删掉聊天用的 Qwen3-0.6B（太弱），新增 Qwen3.5-9B Q4（5.29 GB，质量档；官方没有 6B / 8B 这两档）
- 存储区块编号顺延为 `07 / STORAGE`

## 安装

1. 下载 `RAGchat-1.3.0-arm64.apk` 安装（applicationId `com.dannylam.ragchat`，versionCode 2002；只装这一个，别装 x86_64 / armeabi 分裂包）
2. 首次打开在模型准备页选一个模型下载：Qwen3.5-4B Q4（2.55 GB，默认）、Qwen3.5-2B Q4（1.28 GB，速度档）或 Qwen3-0.6B Q4（396 MB）；不想现在下载就点「稍后配置，先进入」
3. 确认后进主页，点左上 `new` 开始聊

模型不打进 APK；也可以电脑 `adb push` GGUF 到 App 私有目录后点「重新扫描」。

## 已知限制

- 2B 模型会跑题、复读；温度调低能缓解。「思考」功能已固定关闭（会自言自语并把思考内容喷进气泡）。
- 情景记忆（向量检索）、导出 / 导入继承尚未实现。
- 只在 Android 真机（一加 Ace 5 Pro / Android 16）验证过。
