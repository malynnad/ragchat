# 界面改用「纸页与档案」设计语言，撤掉多色主题

2026-11-16 用户要求按 `paper-archive-ui` skill 重排界面，并明确不要多色主题；同时把模型候选收敛到「手机聊天够用」的档位。此前界面是 iOS 分组卡片 + 六档 Nord 强调色，聊天正文区是大圆角气泡，和「档案册」的调性相反。

## 状态

accepted

## 决策

1. **纸在上、玻璃在下**：页面底色用暖白纸渐变（深色炭黑），只有 dock、图标按钮、弹层用毛玻璃。内容卡片是纸面板（圆角 4、发丝描边、四角定位标），不做毛玻璃。
2. **只用一套纸墨色**：删除 `kAccents` / `AccentChoice` / `AppState.updateAccent`，设置页不再有「主题颜色」。层级靠明度（ink / muted / hairline）与透明度，不引入彩色强调色；深色模式仍保留。
3. **编号是结构**：页头 `03 / CONFIG`，区块 `01 / MODEL`、`02 / CANDIDATES`、`03 / PERSONA`、`04 / STORAGE`，记忆条目 `WK-00001`。
4. **字阶收进 7 档**：9 档案码 / 11 dock / 12 次要 / 13 正文 / 14 控件 / 18 区块标题 / 23 报头。`kFontTitle` 由 15.5 → 18。
5. **dock 换玻璃胶囊**：`CupertinoTabBar` 换成 `GlassDock`（54 高、项宽 61.33、选中 12×1.5 墨线），三段：聊天 / 记忆 / 设置。拖拽形变暂不做，保留按压 0.97 与一次性落定。
6. **聊天改纸卡**：用户消息用墨块反白（圆角 4），助手消息是纸卡；不再用彩色气泡。空状态改成「一句状态 + 一句范围」的三段式。
7. **模型候选收敛**：只留聊天 0.6B / 2B 与嵌入 0.6B；4B / 8B / 14B 与 Embedding-4B 删除。0.6B 的镜像 HEAD 实测 200（396,705,472 B）。理由是手机端首字延迟，大模型对纯聊天没有收益。
8. **dock 悬空、不压内容**：胶囊叠在内容之上且没有底衬；滚动体底部留白 120，聊天输入条让出 `kDockReserve`（96），静止时没有任何卡片钻到胶囊底下。
9. **不画四角定位标**：聊天消息密度高，四角标会贴着首字，故聊天气泡关掉 registration；设置 / 记忆 / 编辑页的纸卡保留。
10. **弹窗统一到纸面字阶**：确认框 / 提示框改成自绘纸面（标题 15/600、正文 13/1.6、按钮 14），动作表换成纸面弹层（行高 52、文字 14、发丝分隔），不再用系统 17–20pt 大字。
11. **品牌图标与开机动画**：应用图标换成鲸鱼线稿（各密度 mipmap 重生成），原生 launch 背景放同一张图；Flutter 首帧再播一次 1.1s 动画——图标从 0.86 放大到 1.18，后 45% 透明度归零，然后进主界面；开启「减少动态」直接跳过。
12. **默认人设跟着用户调整**：大肥鱼性格去掉「傲只两成」、口癖收成「哼，才不是；嘿嘿」、称呼改「主人」——按用户在真机上改好的版本回填。

## 后果

- ADR-0010/0011 的人设结论不变，只是默认值同步用户手改版。
- `theme.dart` 只剩纸墨两套主题；`theme_accent_test` 删除，改为 `paper_theme_test`（令牌、字阶、纸卡圆角、区块三层）。
- 弹层圆角 16 → 4，底部弹层底色改纸面。
- 大模型从目录消失，想再跑大模型只能手动导入 GGUF（模型选择器仍按角色过滤文件）。
- 内存页分组由 kind 分组改为按时间顺序单列 + `WK-` 编号。
- 「真机诊断」入口与 `verify_page.dart` 一并删除；要再查 nobodywho 加载只能临时加回页面。
