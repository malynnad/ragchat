# 界面改用「纸页与档案」设计语言，撤掉多色主题

2026-11-16 用户要求按 `paper-archive-ui` skill 重排界面，并明确不要多色主题；同时把模型候选收敛到「手机聊天够用」的档位。此前界面是 iOS 分组卡片 + 六档 Nord 强调色，聊天正文区是大圆角气泡，和「档案册」的调性相反。

## 状态

accepted

## 决策

1. **纸在上、玻璃在下**：页面底色用暖白纸渐变（深色炭黑），只有 dock、图标按钮、弹层用毛玻璃。内容卡片是纸面板（圆角 4、发丝描边、四角定位标），不做毛玻璃。
2. **只用一套纸墨色**：删除 `kAccents` / `AccentChoice` / `AppState.updateAccent`，设置页不再有「主题颜色」。层级靠明度（ink / muted / hairline）与透明度，不引入彩色强调色；深色模式仍保留。
3. **编号是结构**：页头 `03 / CONFIG`，区块 `01 / MODEL`、`02 / CANDIDATES`、`03 / PERSONA`、`04 / STORAGE`，记忆条目 `WK-00001`。
4. **字阶收进 7 档**：9 档案码 / 11 dock / 12 次要 / 13 正文 / 14 控件 / 18 区块标题 / 23 报头。`kFontTitle` 由 15.5 → 18。
5. **dock 换玻璃胶囊**：`CupertinoTabBar` 换成 `GlassDock`（54 高、项宽 61.33、选中 12×1.5 墨线），三段：聊天 / 记忆 / 设置。拖拽形变暂不做，保留按压 0.97 与一次性落定。
6. **聊天改纸卡**：用户消息用墨块反白（圆角 4），助手消息是纸卡；不再用彩色气泡。空状态改成「一句状态 + 一句范围」的三段式。
7. **模型候选收敛**：只留聊天 0.6B / 2B 与嵌入 0.6B；4B / 8B / 14B 与 Embedding-4B 删除。0.6B 的镜像 HEAD 实测 200（396,705,472 B）。理由是手机端首字延迟，大模型对纯聊天没有收益。
8. **dock 悬空、不压内容，键盘弹起时滑走**：键盘一出现，胶囊用 160ms 滑出屏幕；键盘开合会触发一次贴底滚动。两个坑：外层 Scaffold 会把 `viewInsets` 从子树移走，页面自己读不到，所以由 shell 用 `KeyboardDockScope` 传「键盘开着」这个布尔值；内层 Scaffold 必须 `resizeToAvoidBottomInset: false`，否则键盘高度被让两次，输入框和键盘之间空出一格。输入框底部在键盘开时只留 8。键盘收起时输入条会先落到底再被顶起 88px，看起来跳一下：改成底部留白用 `AnimatedPadding`（180ms，与 dock 滑入同一条曲线），系统底部 inset 用 `viewPadding` 常量并入留白，不再靠 `SafeArea` 一开一关切换。：胶囊叠在内容之上且没有底衬；滚动体底部留白 120，聊天输入条让出 `kDockReserve`（96），静止时没有任何卡片钻到胶囊底下。
9. **不画四角定位标**：聊天消息密度高，四角标会贴着首字，故聊天气泡关掉 registration；设置 / 记忆 / 编辑页的纸卡保留。
10. **弹窗统一到纸面字阶**：确认框 / 提示框改成自绘纸面（标题 15/600、正文 13/1.6、按钮 14），动作表换成纸面弹层（行高 52、文字 14、发丝分隔），不再用系统 17–20pt 大字。
11. **品牌图标与开机动画**：应用图标换成鲸鱼线稿（各密度 mipmap 重生成）。开机动画用的那张不是原图：先把白底按亮度转成透明（保留线稿灰阶），再套 20% 圆角 + 26px 高斯羽化遮罩，底部 18% 做 smoothstep 渐隐，让裙摆和网点化进纸里；否则白方块贴在纸色上很突兀。Flutter 首帧播 1.1s——0.86→1.18 放大，后 45% 透明度归零，再进主界面；开启「减少动态」直接跳过。
12. **图标换成水彩人像**（用户提供）：原图背景是近白 #FDFDF9，与纸色 #F4F3EF 差一档；把近白像素按「白度」逐步重映射到 #F4F3EF，水彩灰阶保留。启动器图标用满版纸色交给系统裁切；开机画面另存一份，20% 圆角 + 26px 羽化，边缘化进纸里，冷启动的 window background 也改成纸色，避免先闪白。
13. **开机动画改为「停住再冲出」**：图标落在屏幕中央 120%，停 0.5s，随后 0.35s 内放大到 18 倍冲出画面并淡出，共 0.9s；减少动态直接跳过。
14. **采样参数可调（只有温度）**：04 / SAMPLING 三档（稳定 0.4 / 平衡 0.6 / 活跃 0.9，默认 0.6）热生效。**思考开关做出来后又删掉了**：2B 模型开 `enable_thinking` 会把思考内容当普通 token 喷进聊天气泡，还会死循环（真机实测 5 分钟没停），所以 chat template 里固定 `enable_thinking: false`；另加 45s 生成看门狗，超时自动停并提示。
15. **删库改为「按住填充」按钮**：存储分组里放红色描边的「删除聊天数据」按钮，按下去红色从左往右填满一格（0.9s），填满才弹一次确认；中途松手立刻回退，避免误触。
16. **默认人设跟着用户调整**：大肥鱼性格去掉「傲只两成」、口癖收成「哼，才不是；嘿嘿」、称呼改「主人」——按用户在真机上改好的版本回填。

## 后果

- ADR-0010/0011 的人设结论不变，只是默认值同步用户手改版。
- `theme.dart` 只剩纸墨两套主题；`theme_accent_test` 删除，改为 `paper_theme_test`（令牌、字阶、纸卡圆角、区块三层）。
- 弹层圆角 16 → 4，底部弹层底色改纸面。
- 大模型从目录消失，想再跑大模型只能手动导入 GGUF（模型选择器仍按角色过滤文件）。
- 内存页分组由 kind 分组改为按时间顺序单列 + `WK-` 编号。
- 「真机诊断」入口与 `verify_page.dart` 一并删除；要再查 nobodywho 加载只能临时加回页面。
