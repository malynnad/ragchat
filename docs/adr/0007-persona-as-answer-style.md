# 人设以「回答风格预设」回归

> **2026-11-16 扩展**（ADR-0009）：风格预设升级为完整人设卡（名字/性格/风格/称呼/边界，多卡可切换）；「不可覆盖底线」条款随 RAG 底线移除而失效，百字级限制的教训保留。

ADR-0003 转向 RAG 知识库时废弃了旧陪聊人设（无记忆、无角色扮演）。2026-11-15 v2 用户要求「设置增加人设 prompt，可针对不同使用场景优化回答内容」。评估后以受限形式回归：人设只作为**回答风格句**，不恢复陪聊、不引入记忆。

## 状态

accepted

## 决策

1. **预设四档**：默认（无附加风格句）、通俗讲解（白话 + 比喻）、严谨考据（书面语、逐条引用）、自定义文本。预设文案 ≤50 字——8B 模型指令遵循有限，风格句越短越稳。
2. **system 消息结构固定**：RAG 底线（仅按资料回答、[n] 引用、不编造）永远在前；风格句以「回答风格：…」追加在后。自定义文本只能追加风格段，**不可覆盖底线**。
3. **保存即生效**：风格句在下一问组装消息表时带入，无需重载模型（与换 GGUF 模型不同）。
4. **持久化**：personaId / customPersona 存 settings.json，旧格式向后兼容默认值。

## 后果

- ADR-0003 排除项的受限反转：有「风格」，无「人设记忆 / 陪聊」。旧 ADR-0001（事实提取记忆）仍废弃。
- 风格只影响表达，不影响检索与拒答判定；阈值闸门在生成之前，风格句无法让模型「更敢编」。
- 测试：session_context_test.dart 断言底线始终在前、风格句追加、空自定义回退默认。
- 真机冒烟需验证：同一问题切换「通俗讲解」后答案风格可见变化。
