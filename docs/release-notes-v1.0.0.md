# RAGchat 1.0.0

本地优先的记忆陪聊 App 第一个发行版：模型在手机端跑，聊天记录、记忆、人设全部留在本机。

## 这个版本有什么

- **端上推理**：nobodywho（llama.cpp）在 CPU 上直接跑 GGUF，不走云端
- **长期记忆**：从对话提取事实 / 偏好 / 事件 / 关系，带重要度，可编辑、停用、删除
- **会话持久化**：关掉 App 再打开，最近会话还在；`new` 开新对话时自动整理记忆
- **单卡人设**：名字 / 性格 / 说话方式 / 口癖 / 称呼 / 边界，六项短字段，改完下一轮生效
- **采样可调**：温度三档（稳定 0.4 / 平衡 0.6 / 活跃 0.9），即时生效
- **模型可选 4B**：新增 Qwen3.5-4B Q4（2.55 GB）作为默认档，2B 留作速度档；首次打开可以先「稍后配置」进界面
- **可选云端后端**：设置里能切到 DeepSeek（或任意 OpenAI 兼容 API），key 存系统 Keychain/Keystore；不填 key 时仍走本地。默认模型 `deepseek-flash`
- **人设随手切**：本地默认短人设「小暖」，云端默认长人设「傲娇鱼」（2.3k 字）；切后端自动换，用户改过的不动
- **纸页与档案界面**：暖白纸底 + 档案编号 + 只在交互层用玻璃，单一纸墨色
- **细节**：45 秒生成看门狗、键盘弹起时 dock 滑走、删库需按住进度条填满

## 安装

1. 下载 `ragchat-1.0.0-arm64.apk` 安装（applicationId `com.dannylam.ragchat`；只装这一个，别装 x86_64 / armeabi 分裂包）
2. 首次打开在模型准备页选一个模型下载：Qwen3.5-4B Q4（2.55 GB，默认）、Qwen3.5-2B Q4（1.28 GB，速度档）或 Qwen3-0.6B Q4（396 MB）；不想现在下载就点「稍后配置，先进入」
3. 确认后进主页，点左上 `new` 开始聊

模型不打进 APK；也可以电脑 `adb push` GGUF 到 App 私有目录后点「重新扫描」。

## 已知限制

- 2B 模型会跑题、复读；温度调低能缓解。「思考」功能已固定关闭（会自言自语并把思考内容喷进气泡）。
- 情景记忆（向量检索）、导出 / 导入继承尚未实现。
- 只在 Android 真机（一加 Ace 5 Pro / Android 16）验证过。
