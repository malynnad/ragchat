# RAGchat 1.4.1

修两个能明显感觉到的毛病：**聊完的事没进记忆**、**模型分不清早晚**。也是本轮唯一的功能变化。

## 1.4.1 修复

### 记忆不再只提取最后 6 轮

上一版做记忆提取时，只把会话的**最后 6 轮**交给模型。会话一长，前面聊过的事永远进不了记忆——
白天聊完去哪儿玩，晚上又聊别的，新建对话时白天那段早被挤出窗口。

- 改成按时间顺序**分批跑完整个会话**（每批 6 轮，单次上限 12 批 / 72 轮，超出留到下次）
- 某一批解析失败就停手，不再继续白烧 token
- 提示词里明确要求记「事件」：做过的事、去过的地方、见的人，**只发生一次也要记，并写清日期**
- 提取时会带上「今天日期」，事件能写成「2026-11-27 去博物馆看展」

### 不再假装记得

记忆里没有的事，小模型也会顺着上下文编。现在 system 里多了两句约束：

- 有记忆时：「以上是你能确定的全部记忆；没列到的事就说不记得，不要编。」
- 一条记忆都没有时：「你还没有关于用户的记忆；不知道就说不记得，不要编。」

这两句都算进 800 token 预算，不会挤掉人设。

### 模型知道现在是几点了

以前 system 里没有时间，早上说「晚安」、深夜说「早上好」都是这么来的。现在每轮都带：

```
现在是2026年11月28日 周六 上午 11:14；这是准确时间，用户问日期、时间、星期就直接回答，
不要说不知道，也别把早晚说错。
```

时段分成七档（深夜 / 早上 / 上午 / 中午 / 下午 / 傍晚 / 晚上），小模型不用自己换算 24 小时制。

### 界面

- 设置 → 01 / MODEL 的「标定」「自检」各占一行，后面跟灰字说明；字号与其它按钮统一
- 修掉系统字号放大时这两个按钮撑出卡片的问题

## 安装

1. 下载 `RAGchat-1.4.1-arm64.apk`（applicationId `com.dannylam.ragchat`，versionCode 2006），覆盖安装不会丢数据
2. 嵌入模型（Qwen3-Embedding-0.6B，约 640 MB）不是必须的；装了才做记忆检索
3. 想让旧会话重新提取记忆：目前只支持「从当前会话提取」，旧会话没有入口重跑

## 已知限制

- 9B 首次加载 40–60 秒，长回答可能到分钟级；要快换 2B / 4B
- 检索阈值只针对 Qwen3-Embedding-0.6B 标定过，换嵌入模型请先跑「标定」
- 自检的 12 道问题固定，命中率随记忆内容变化，不代表模型好坏
- 只在 Android 真机（一加 / Android 16，arm64）验证过
